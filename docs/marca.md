# Marca

Hilvanar es unir telas con puntadas largas antes de coser definitivo. Hilvana une los hilos de los
clientes que llegan por distintos canales en una sola conversación, sin coser nada a la fuerza.

## Archivos

| Archivo | Uso |
|---|---|
| `assets/brand/logo.svg` | Logo horizontal sobre fondo claro (lino). |
| `assets/brand/logo-oscuro.svg` | Logo horizontal sobre fondo tinta. |
| `assets/brand/icono.svg` | Ícono de app (512 × 512, esquinas redondeadas). |
| `assets/brand/simbolo.svg` | Símbolo solo, para estados vacíos y favicon. |
| `assets/brand/mono.svg` | Versión monocromática. |
| `app/assets/brand/logo*.svg` | Variantes para la app, generadas por `scripts/app-icons.sh`: sin lienzo de fondo y sin el lema (a 72 px es ilegible; la entrada lo muestra como texto). |

El símbolo es una burbuja de conversación cosida con puntadas de hilván, tres hebras que entran (los
canales) y se juntan en un solo hilo, y la aguja que las une.

## Color y tipografía

| Nombre | Hex | Uso |
|---|---|---|
| Lino | `#F2ECE1` | Fondos |
| Tinta | `#1E2B45` | Texto y acciones principales (contraste mayor a 11:1 sobre lino) |
| Hilo | `#B5502B` | Acentos, íconos y texto grande (4,3:1 sobre lino: no para texto pequeño) |
| Hilo claro | `#D9825F` | Acentos sobre fondo tinta |

Tipografías con licencia libre (SIL OFL 1.1): **Fraunces** para la marca y los títulos; **IBM Plex Sans**
para el texto.

## Lo que no se hace

- Degradados, brillos, destellos, robots, cerebros ni "chispas" de IA.
- Frases como "potenciado por IA" o "la IA procesó tus interacciones".
- Logos de WhatsApp, Instagram, Messenger, Meta o Shopify dentro del logo, el ícono o el nombre.

## Voz

Lenguaje de taller y oficio, en español natural: "Tienes 3 conversaciones esperando", no "La IA ha
procesado 3 interacciones". El asistente se presenta como "asistente automático de [negocio]" y se
identifica como automático ante el cliente final, sin estética de ciencia ficción.

## Marcas de terceros

Se mencionan únicamente para describir compatibilidad ("recibe mensajes de WhatsApp"), escritas
como texto y respetando sus guías de marca.
