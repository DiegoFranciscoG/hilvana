# Fixtures sintéticos

Webhooks de ejemplo armados con la forma documentada por Meta y Shopify (docs/investigacion.md #21, #28,
#30, #32, #33). **Todos los datos son ficticios**: nombres inventados, números con prefijo de prueba y
correos en el dominio reservado `.test`. Sirven para probar los conectores, el laboratorio (T-08, T-09) y
para reproducir tráfico en local sin depender de Meta.
